# 学习目标管理台

一个**完全离线、单文件、零外部依赖**的 HTML 工作台，专门管理**有终点与总量**的学习目标（背完 2000 单词、读完 440 页书、上完 40 课时），而不是无限期的习惯打卡。

## 文件

| 文件 | 用途 |
| --- | --- |
| `学习目标管理台.html` | 主文件。下载后双击即可用（离线可用，无需联网） |
| `index.html` | 与主文件完全相同，供 GitHub Pages 在线打开使用 |

## 核心机制

- **每日建议量** = 剩余量 ÷ 剩余天数，打卡时预填、可改
- **预计完成日** 按近 7 天平均速度推算，与截止日对比显示「提前 N 天 / 拖后 N 天」；近 7 天记录天数不足 2 天时显示「暂无推算」，不编数字
- **连续天数**：每周一重置 1 个休息日额度 —— 本周首漏不中断，二漏才断
- **昨日漏卡**自动置顶：黄卡 = 休息日额度兜住、连续保留；红卡 = 额度用完、连续中断、滚入今日
- **逾期**显示逾期天数，提供「立即打卡」与「调整计划」两个出口
- **补记**：一天可多笔记，可补记最近 6 天，带「补」标，按真实日期计入连续天数与推算
- **障碍与预案**：填「最易拦住我的障碍」+「如果它出现，我就……」，卡片上常驻提醒

## 四个 Tab

1. **今日**：首屏新建按钮 + 待处理/可打卡卡片，底部保留醒目新建入口；支持编辑与二次确认删除
2. **看板**：进度环 + 三核心数字（完成率 / 连续天数 / 预计完成日）+ 预案 + 最近 10 条可删记录 + 手写 SVG 绘制的近 14 天投入分钟分目标堆叠柱状图（无分钟数据不硬凑）
3. **周报**：周一至周日汇总投入量 / 天数 / 分钟，附上周同口径环比；可查历史周；保存「保持 / 问题 / 尝试 / 下周预案」四栏（输入即时保存）；一键生成含环比与四栏的周报文本
4. **我的**：导出 JSON、覆盖确认后导入、旧版迁移、清空示例、输入「清空」清全部、添加到主屏三步说明

累计 20 条打卡记录后，顶部出现可直接导出的温和备份横幅。达成目标时有彩带动效。

## 数据说明

- 数据只存在**你自己浏览器的 localStorage** 里（键名 `wb_goaltracker_v2`），不联网、不上传、无账号体系
- 换设备 / 换浏览器请用「我的 → 导出 JSON → 导入恢复」迁移
- 若通过 Pages 在线打开：页面可公开访问，但数据仍留在各自设备本地；建议定期导出备份

## 手机使用（3 步）

1. 在手机浏览器打开本项目的在线地址（或把 HTML 文件传入手机后打开）
2. 点浏览器菜单「添加到书签 / 收藏」
3. 再点「添加到主屏幕 / 添加到桌面」，桌面出现图标，点开即用

## 技术约束

单文件 HTML，所有 CSS / JS / 图标 / 图表全部内联：不引任何 CDN、字体、图标库或图表库；图标与图表均为手写内联 SVG，不使用 emoji；响应式三档布局（手机底部四 Tab 单列 / 平板顶部横导航 / 电脑左侧边栏多栏）。
